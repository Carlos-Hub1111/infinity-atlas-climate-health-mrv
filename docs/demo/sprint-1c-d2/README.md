# Sprint 1C-D2 local UAT package

Local-only review package for the final Sprint 1C-D2 corrections. The public Cloudflare
deployment and remote D1 database were not changed.

## Scope represented

- separate Open-Meteo provider and reproducible JSON links;
- resilient filters and a persistent geoprivacy-aware map;
- dismissible chart tooltips and selection interpretation;
- public sequence numbers 1-6 with technical IDs 101-106 retained;
- filtered PDF labels and factual selection narratives;
- canonical technical CSV and Excel-friendly Spanish CSV;
- cool institutional visual treatment;
- explicit separation between the public surface and internal roles.
