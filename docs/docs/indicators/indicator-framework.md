# Climate-Health MRV Indicator Framework

This document presents an initial indicator framework for the Infinity Atlas Climate & Health MRV Toolkit.

The indicators are designed to help local actors monitor climate-related environmental risks affecting children’s health.

## 1. Exposure Indicators

These indicators help identify environmental risks that may affect children and vulnerable communities.

Examples:

- number of waste pollution hotspots identified;
- number of water contamination risk points reported;
- number of heat-prone areas mapped;
- number of air quality concern points registered;
- number of hazardous waste exposure sites identified;
- number of schools located near environmental risk areas;
- number of health facilities located near environmental risk areas.

## 2. Vulnerability Indicators

These indicators help estimate who may be more exposed or less able to respond.

Examples:

- number of children potentially exposed to mapped risks;
- number of vulnerable households located near risk areas;
- number of schools lacking climate-health risk information;
- number of communities without accessible environmental data;
- vulnerability score by location or community.

## 3. Response Indicators

These indicators track whether action is being taken.

Examples:

- number of local response actions recorded;
- number of municipal departments engaged;
- number of community reports addressed;
- number of schools or community actors trained;
- time between risk identification and response action.

## 4. Mitigation and Prevention Indicators

These indicators measure progress in reducing environmental and health-related risks.

Examples:

- percentage of identified risk points with follow-up action;
- percentage of waste hotspots reduced or managed;
- percentage of communities covered by risk awareness activities;
- number of preventive actions implemented;
- estimated reduction in exposure risk.

## 5. Data Quality Indicators

These indicators help ensure that the MRV system produces reliable information.

Examples:

- percentage of reports with complete data;
- percentage of reports with geographic location;
- percentage of reports with supporting evidence;
- number of validated data records;
- number of updated records per month.

## 6. Community Participation Indicators

These indicators measure engagement and local ownership.

Examples:

- number of community members contributing reports;
- number of schools participating in data collection;
- number of local workshops conducted;
- number of community-based observations registered;
- level of participation by youth and local stakeholders.
