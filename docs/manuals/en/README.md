## Important limits

- The guides describe implemented behavior only.
- `demo-validator` remains inactive and hidden in the primary demonstration.
- Institutional validation does not automatically publish a record.
- Institutional soft deletion does not automatically withdraw an item from the separate public D1 dataset.
- No guide contains a functional password or signing secret.
- InfinityAtlas is not a clinical diagnosis tool and does not independently verify territorial events.
